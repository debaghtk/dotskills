# GLOSSARY.md Format

`GLOSSARY.md` is the workspace's canonical language.

```md
# {Topic} Glossary

## Terms

**{Term}**:
{A tight one- or two-sentence definition.}
_Avoid_: {Ambiguous aliases}
```

Add a term only after the user demonstrates understanding. Pick one preferred term, flag ambiguities, and use established glossary terms in later definitions and lessons. Group terms only when natural clusters emerge. Revise definitions as understanding deepens.
