# RESOURCES.md Format

```md
# {Topic} Resources

## Knowledge

- [{Resource title}]({URL})
  {What it covers and when to use it.}

## Wisdom (Communities)

- [{Community name}]({URL})
  {What real-world feedback it provides and when to use it.}

## Gaps

- {Knowledge the mission needs but no trustworthy source currently covers.}
```

Prefer primary sources, recognized experts, peer-reviewed work, and strongly moderated communities. Annotate every entry. Remove weak or off-mission resources instead of accumulating links. Record when the user opts out of community participation.
