# Learning Record Format

Create `learning-records/` only when the first record is needed. Name records sequentially: `0001-slug.md`, `0002-slug.md`, and so on.

```md
# {Short title}

{In one to three sentences: what was demonstrated or established, and why it changes future teaching.}
```

Write a record when the user demonstrates non-trivial understanding, discloses relevant prior knowledge, corrects a misconception, or changes the mission. Do not record mere coverage, duplicate glossary definitions, or keep session logs.

Add optional evidence or implications only when useful. If later learning contradicts a record, mark it `Status: superseded by LR-NNNN` rather than deleting it.
